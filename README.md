# 🎨 AI Web Design Evaluation Platform

An AI-powered platform that evaluates website designs by analyzing screenshots, identifying UI/UX issues, and generating actionable design feedback. The platform helps designers, developers, and product teams improve usability, accessibility, and visual consistency using AI.

---

## ✨ Features

* 🤖 **AI-Powered Design Review**

  * Analyze website screenshots using Large Language Models.
  * Receive detailed UI/UX feedback with severity levels.

* 📸 **Screenshot Upload**

  * Upload website screenshots for instant evaluation.
  * Support for multiple image formats.

* 🎯 **Issue Detection**

  * Layout inconsistencies
  * Alignment problems
  * Color contrast issues
  * Typography improvements
  * Accessibility recommendations
  * Visual hierarchy analysis
  * Spacing and responsiveness suggestions

* 📊 **Evaluation Reports**

  * Structured design feedback
  * Improvement suggestions
  * Overall design score
  * Categorized issues

* 🔒 **Authentication**

  * Secure user login
  * Personal evaluation history

* 📱 **Responsive Interface**

  * Optimized for desktop and mobile devices.

## 🚀 Getting Started

### Prerequisites

* Java 21+
* Node.js 20+
* PostgreSQL
* Maven

### Backend

```bash
cd backend

./mvnw spring-boot:run
```

### Frontend

```bash
cd frontend

npm install
npm run dev
```
